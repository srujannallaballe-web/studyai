# StudyAI

StudyAI is a front-end prototype for an AI study assistant.

## Files

- index.html — website structure
- style.css — website design
- script.js — interactions

## Important

This is only a front-end prototype. The PDF selector works locally in the browser, but the PDF is NOT uploaded to an AI/server yet.

The next development stages can add:
- real PDF processing
- AI API integration
- user accounts
- database/storage
- a real student dashboard
- payments
- deployment and a custom .com domain
